作成: 2026-11-16 ／ 背景は `docs/backup-plan.md`・`HANDOFF.md` §4 の項目92。

> **なぜやるか**＝バックアップがGoogle Driveに入るとき、rclone利用者みんなで使う**共用の名札（client_id）**を見せている。

### 今日わかったこと（再開時に効く）

1. **バックアップのあるGoogleアカウントは `30nensyouten@gmail.com`**（`shigeyasusaki@gmail.com` ではない）。山②Aの許可画面では必ずこちらでログインする。
2. **Macのrcloneは PATH に無い**。`rclone` では `command not found`。**`~/bin/rclone` とフルパスで打つ**。
3. **コマンドにクォートを付けない**。`"` を付けると `dquote>` が出て固まる（Control+C で脱出）。
4. **値は変数に入れてから実行すると事故らない**:
   ```
   ID=        ← クライアントIDを貼り付け
   SECRET=    ← シークレットを貼り付け
   echo "$ID"             # .apps.googleusercontent.com で終わっていればOK
   echo "長さ: ${#SECRET}"  # 35前後ならOK
   ~/bin/rclone authorize drive "$ID" "$SECRET"
   ```
5. **`エラー 401: invalid_client` で止まっている**。IDとシークレットの順番は確認済みで逆ではない。→ **作成直後の浸透待ち**の可能性が高い（Googleが「5分から数時間かかることがある」と明記）。**時間をおいて再実行**する。直らなければ、コンソールのクライアント詳細で**コピーアイコンを使って**IDを取り直す。
6. **ID・シークレットの控え**＝Mac標準の「パスワード」アプリ、項目名「**30nen-backup の名札**」（ユーザ名＝ID／パスワード＝シークレット）。
7. 承認済みドメインは**URLを入れた後**に「次のドメインが見つかりません」と赤字で出て気づく。`30nen.com` を `+ ドメインの追加` で登録し、**ページ下の「保存」1回**で全部まとめて保存される。
8. 「アプリの検証が必要です／検証センターに移動」は**押さない**（審査は不要）。

## まず全体像（たとえ話）

**「すでに走っている車に、自分名義のナンバープレートを取りに行く」**作業。アプリを作るのでも、プログラムを書くのでもない。

| たとえ | 実際 |
|---|---|
| 🚚 車 | **rclone**（もうある。毎晩走っている） |
| 🛣 道路 | Google Drive |
| 🏢 倉庫 / 📦 荷物 | `30nen-backup` フォルダ / 預けてある控え |
| 🔑 倉庫の鍵 | 暗号化パスワード（**今日は一切使わない**） |
| 🔢 ナンバープレート | **client_id** |
| 🖋 実印 | **client_secret** |
| 🏛 役所 | Google Cloud Console |

いま付いているのは**レンタカー屋の共用プレート**で、その制度が廃止される。だから**自分名義のプレートに付け替える**。

山①の各手順は、役所の窓口でいえばこういうこと:

| 手順 | 役所でいうと |
|---|---|
| A. プロジェクト | 申請用の**案件ファイルを1つ作る** |
| B. Drive API | 「**この車は "Drive通り" を走ります**」と道路を申告 |
| C. 同意画面 | **申請書の表紙**（誰が・連絡先・車の名前）。「外部」＝個人の車 |
| D. スコープ／テストユーザー | **何をしてよいかの範囲**と、**運転する人の登録** |
| E. 公開（PUBLISH） | **仮ナンバー → 本ナンバー**。仮のままだと1週間で失効 |
| F. OAuthクライアント | **プレートと実印の交付**。「デスクトップアプリ」＝車種の申告 |

山②は「**持ち主が『この車に荷物の出し入れを任せます』と署名し（ブラウザで許可）、実際にプレートを取り付ける**」。

> **安心材料**＝今日触るのは「車に付いている板」だけ。**倉庫の荷物（控え）も鍵（暗号化パスワード）も一切触らない。** 手数料も無料。

## 山①：Googleで自分専用の名札を作る ［SAKI］（約30分）

> 場所＝ **Google Cloud Console**（`https://console.cloud.google.com/`）。
> ログインは**バックアップを預けているGoogleアカウント**で行う。

### A. プロジェクトを作る
- [ ] 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `30nen-backup` など → 作成。

### B. Drive API を有効にする
- [ ] 「APIとサービスを有効化」→ `Drive` で検索 →「**Google Drive API**」→「有効にする」。

### C. 同意画面（OAuth consent screen）を作る
- [ ] 左メニュー「認証情報」→「**同意画面を構成**」→「開始」。
- [ ] アプリ名・サポートメールを入力。
- [ ] 対象（Audience）＝「**外部（External）**」を選ぶ。※Google Workspaceを使っていないため。
- [ ] 連絡先を入力 → 規約に同意 → 作成。

### D. 権限（スコープ）とテストユーザー
- [ ] 「データアクセス」でスコープを追加:
  - `https://www.googleapis.com/auth/drive`
  - `https://www.googleapis.com/auth/docs`
- [ ] 「対象」→「+ ユーザーを追加」→ **自分のGmailを追加** → 保存。

### E. ⚠ アプリを「公開」する（最重要）
- [ ] 「対象（Audience）」→「**アプリを公開（PUBLISH APP）**」→ 確認。
- [ ] ボタンが押せない場合＝「ブランディング」でホームページとプライバシーポリシーのURL（上の表）と承認済みドメイン `30nen.com` を入れて保存してから戻る。
- [ ] 公開後の表示が「**本番環境（In production）**」になっていることを確認。※「テスト中」のままなら1週間で切れる。

### F. 名札（OAuthクライアント）を作る
- [ ] 「概要」→「**OAuthクライアントを作成**」→ 種類は「**デスクトップアプリ（Desktop app）**」→ 作成。
- [ ] 表示された **クライアントID** と **クライアントシークレット** を控える。
- [ ] ⚠ **この2つはチャットに貼らない**（秘密の扱い。山②では自分の画面で直接入力する）。

## 山②：サーバーに貼り替える ［一緒に］（約15分）

> 前提＝サーバーの設定ファイルの控えは取得済み
> （`/root/.config/rclone/rclone.conf.bak-beforeclientid-20261116`・2026-11-16取得）。

### A. ［SAKI］Macのターミナルで許可を取る
```
rclone authorize "drive" "（クライアントID）" "（クライアントシークレット）"
```
- [ ] ブラウザが開く → **バックアップ用のGoogleアカウント**でログイン → 許可。
- [ ] 「このアプリは確認されていません」と出たら →「詳細」→「（アプリ名）に移動」で進む。※自分で作ったアプリなので問題ない。
- [ ] ターミナルに出た**長い文字列（トークン）**をコピー。

### B. ［SAKI］サーバーに貼り替える
```
ssh -i ~/.ssh/30nen_vps root@162.43.43.144
```
につないでから、1行ずつ:
```
rclone config update gdrive client_id "（クライアントID）" client_secret "（クライアントシークレット）"
```
```
rclone config update gdrive token '（コピーしたトークン）'
```
- [ ] ⚠ トークンは**シングルクォート `'` で囲む**（中に記号が入っているため）。

## 困ったとき

- **元に戻す**＝`cp /root/.config/rclone/rclone.conf.bak-beforeclientid-20261116 /root/.config/rclone/rclone.conf`。共用名札のまま元どおり動く（廃止までは）。
