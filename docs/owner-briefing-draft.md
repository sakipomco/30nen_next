## 1ページ目 ── なぜサイトを作り直すのか

### いまの三十年商店（WordPress版）の困りごと

三十年商店は、いま **WordPress（ワードプレス／世界中で使われているサイト作成ソフト）** で動いています。
2024年の開店から書き手も20人を超え、記事は8,100本を超えました。
ここまで支えてくれた頼もしい仕組みですが、長く続けていくうえで、いくつか引っかかりが出てきました。

- **書き手の投稿画面がややこしい**
  「下書き／公開」「カテゴリー」「アイキャッチ」など、初めての人にはボタンが多すぎる。
- **写真がそのまま重い**
  WordPressは原寸の写真と複数サイズのコピーを保存するため、画像フォルダがすでに **約71GB**（30GBの壁を越えてサーバーの容量を圧迫）。このペースだと30年で1テラ超えになります。
- **管理の手間**
  WordPress本体・プラグインのアップデート、不具合対応など、人手が要る。

### 新サイトのゴール

「30年つづける」を本気で考えて、土台から作り直すことにしました。

- **自分で調整・修正しやすいサイト** にする
- 書き手のための **シンプルな投稿画面**（迷うところを減らす）
- **記事も写真もぜんぶ新しいサイトへ運ぶ**（8,100本のこれまでを途切れさせない）
- **データは自分たちの手元に持つ**（よそのサービスが終わっても困らない）

> 専門用語メモ
> ・**SaaS（サース）**＝月額で借りるネットサービスのこと。便利だけど積み重なると重い。
> ・**サーバー**＝サイトのデータを置いておく、ネット上の置き場所。

## 2ページ目 ── 何が変わるか（書き手目線で）+ ここまでの道のり

### 書き手にとっての主な変化

新しい投稿画面は **「迷わない・ヌケがない・落ちない」** を意識して作りました。

| いままで | これから |
| --- | --- |
| 連載（カテゴリー）を毎回選ぶ | **担当の連載が自動でセット**（書き忘れゼロ） |
| 写真を一度パソコンで縮める | **そのまま貼り付け・ドラッグでOK／自動で軽くする** |
| 書きかけが消えると涙 | **10秒ごとに自動保存**（タブを閉じても残る） |
| 「下書き」と「公開」の違いが見えにくい | **ボタンが「投稿する」「下書き保存」の2つだけ** |
| アイキャッチ画像を忘れて公開しがち | **未設定なら「このまま公開しますか？」と確認**（必須にはせず注意だけ） |
| 年齢は毎年の更新が必要 | **誕生日を一度入れれば、満年齢が自動で表示**（更新不要） |
| 過去に上げた写真をどこに置いたか分からなくなる | **「画像フォルダ」**で一覧できる |

書き手向けには、**日本語・スペイン語の2言語のガイドPDFを完成済み**です。
切替前に全員へお配りします。

### サイト全体のデザイン

見た目は、いまの三十年商店をできるだけそのまま残します。
暖簾（のれん）のロゴ、明朝体、白い背景、左右3カラム ── これまでの雰囲気をそこなわずに、中身だけが新しい仕組みになります。
スマートフォンの右下にハンバーガーボタン（≡）が出る点も、いまと同じです。

### ここまでに済んだこと

ざっくり順番で言うと、こんな段取りで進んできました。

1. **設計**（どんなデータをどう持つかの土台づくり）
2. **書き手の投稿画面**（ログイン・記事の作成・編集・写真貼り付け など）
3. **連載と書き手の名簿**（自動ひもづけの仕組み）
4. **公開ページ**（トップ・記事ページ・連載ページ・スマホ表示）
5. **左メニュー5項目**（当店について／沿革／書き手募集／利用規約／プライバシーポリシー）
6. **検索エンジン対策**（サイトマップ・OGP・旧URLからの自動転送）
7. **記事まるごと運ぶリハーサル**：本番の **8,102本** を練習用に取り込み、エラー0 で成功
8. **新しいサーバー（Xserver VPS）に新サイトが立った**（6月25日：本契約完了・本番建て直し成功）

> 専門用語メモ
> ・**VPS**＝Virtual Private Server。共用サーバーよりちょっと上の、自分専用の小さなサーバー。月1,500円ほど。
> ・**OGP**＝SNSなどで記事リンクを貼ったとき、画像や見出しがきれいに出る仕組み。
> ・**サイトマップ**＝サイト内のページ一覧。検索エンジン（Google）がもれなく見にきてくれるための案内図。

## 3ページ目 ── 今後の段取り（切替日とお知らせ）

### 切替の目標日

**2026年 7月下旬**（具体的な日は7月上旬に確定）。
うまくいかなければ **8月末まで延期できる**ように余裕をもたせています。
無理に7月下旬で切らず、「戻せる準備」が整ってからGOです。

### 切替の前にやること（7月上〜中旬）

- 🔒 **バックアップの「戻せる」テストに合格**
  毎日DB（記事の本体）、週1で写真をGoogleドライブへ自動保存。
  万一サーバーが壊れても、まっさらなVPSに **戻せることをテストして合格** することを切替の絶対条件にしています。
- 🔒 **httpsの鍵マークをつける**（無料の証明書 Let's Encrypt）
- 📩 **書き手のみなさんへガイド配布＋お知らせ**
  - 日本語・スペイン語のPDFガイドをお配り
  - 「7月◯日から新サイトに切り替わります」のお知らせ
- 🧪 **書き手2〜3名で実際に投稿テスト**（本切替の前の最終リハ）

### 切替日にやること（数時間で完了見込み）

1. WordPress側で **新規投稿を一時停止**（書き手にも前日に告知）
2. 切替日の最新記事までを **もう一度新サイトへ取り込み**（差分だけ）
3. **本物のURL（30nen.com）を新サイトに向け直す**
4. 旧URLでアクセスしてきた人を **新サイトの同じ記事へ自動で連れていく**（301転送＝もう実装済み）
5. Googleに **新しいサイトマップを登録**（Search Console）
6. みんなで開いて確認 → **公開再開**

### 切替の後（7月下旬〜）

- **コーダーこうちゃんに連絡する**（無事に切り替わったことのご報告）
- 旧 WordPress は **しばらく読み取り専用で温存**（何かあったらすぐ戻せるように）
- 1〜2ヶ月、表示や検索順位に問題がないことを見守り、落ち着いたら旧サイトを正式にお休み
- 書き手の声を聞きながら、投稿画面の細かい改善を続ける

### 書き手のみなさんにお願いすること

- **7月上旬**：ガイドPDFを読む／新サイトのログイン情報（メール・仮パスワード）を受け取る／受取後に各自ログインし、**「パスワード変更」**と「myPROFILE」で **「誕生日（新項目）」**記入・他の項目の確認をしてください
- **7月中旬**：希望者2〜3名で新サイトに試し投稿（最終リハ）
- **切替前日**：旧サイト（WordPress）での投稿はその日まででお願いします
- **切替日の翌日〜**：新サイトで普段どおりの投稿を再開／引っかかった点は気軽にご連絡

### 店主の二人でやること

- 切替日の **GO/NO-GO判定**（戻せるか／書き手のガイドが行き届いたか）を一緒に決める
- 切替日は **二人とも対応できる時間帯** に行いたいです
