### 山③で学んだこと（次回の復旧で必ず生きる）
1. **rcloneのパスは二重フォルダ**＝正しくは `gdrive-crypt:30nen-backup/db/`・`gdrive-crypt:30nen-backup/uploads`（cryptの包み先が既に `gdrive:30nen-backup` で、スクリプトの保存先指定でもう一段 `30nen-backup/` が掘られている）。`gdrive-crypt:db/` では「not found」になる。
2. **写真を全部戻し終えてからアプリを起動する**（起動後に足した写真は404になる→写真完了後にアプリ再起動で解消）。
3. `npm ci` 後は必ず `npm rebuild better-sqlite3 sharp --foreground-scripts`（deploy-notes §3-4 の落とし穴・今回も再現）。
4. 実測時間＝鍵の実証〜開店確認まで約1時間（＋写真の全量ダウンロード約4.5時間・放置でOK）。Google Driveは16,000枚規模だと数時間かかる前提で段取りする。
