# リードテキストの控え

ロゴ下（左コラム）に出る「リードテキスト」の控え。
編集は管理画面の **設定**（`/admin/settings`）。保存先は DBの `site_settings` テーブル（`key='lead_text'`）。

> **なぜ控えを残すか**＝入れ替えると前の文面はDBから消える（履歴が残らない）。
> お詫びなど一時的な掲示のあと「元に戻したい」ときのために、ここに置いておく。

## ⚠ 知っておくこと

- **記事を1本読んでいるページ（`/posts/◯◯`）には出ない**。日記ページでは代わりにお便りフォームを上に出す作りのため（`src/components/public/sidebar-left.tsx` の `LeadTextSlot`）。SNSから記事に直接来た人には見えない。
