## 5. タイポグラフィ（文字ツメ）の仕様

### 5-1. 基本方針

| 文字種 | 現行の設定 | 新システムの設定 | 変更の意図 |
|--------|----------|----------------|----------|
| ひらがな・カタカナ | `letter-spacing: -0.05em` | **同じ（-0.05em）** | 現行のまま維持 |
| 漢字 | `letter-spacing: -0.05em`（html ベース） | `-0.03em` に緩める | 少しゆったりさせる |
| 欧文・英字（a〜z / A〜Z） | `.en` クラスで `letter-spacing: normal`（**手動マークアップ**） | `font-kerning: normal` で自動対応（クラス不要） | 投稿者が手動でクラスをつける手間を廃止 |
| 数字（アラビア数字） | 欧文と同扱い（`.en` クラスを手動付与） | 欧文と同じく自動対応 | 同上 |

> **「`.en` クラス」とは？**  
> 現行の WP テーマでは「Instagram」「Twitter」など英字部分に `<span class="en">...</span>` を
> 手動でタグ付けして文字間を調整していました。新システムではこの作業をなくします。

---

### 5-2. CSS の実装方針

```css
/* ── ① 全体のベース設定（html または body に適用） ── */
html {
  letter-spacing: -0.03em;       /* 現行 -0.05em より少しゆるく */
  font-kerning: normal;          /* 欧文・数字のカーニング（字間の自動調整）を有効化 */
  font-optical-sizing: auto;     /* 文字サイズに応じた自動補正（現行も使用中） */
}

/* ── ② 本文（記事本文・説明文など）── */
p, li, .prose {
  letter-spacing: -0.04em;      /* 現行 -0.07em より大幅に緩める */
  line-height: 2.0;             /* 行間は現行（2.8rem 相当）を維持 */
}

/* ── ③ 見出し（記事タイトルなど目立つ箇所）── */
h1, h2, h3 {
  letter-spacing: 0em;          /* 詰めない（広さが品格につながる） */
  font-kerning: normal;         /* 欧文見出しのカーニングを有効化 */
}

/* ── ④ ナビ・リンク・UI テキスト ── */
a, nav, button {
  letter-spacing: -0.03em;      /* 現行 -0.1em より大幅に緩める */
}

/* ── ⑤ サイト名・ロゴ周辺 ── */
.site-title {
  letter-spacing: 0.05em;       /* サイト名はあえて少し広げてブランド感を出す */
}
```

---

### 5-3. 欧文・数字の自動カーニングの仕組み

現行の手動 `.en` クラスに代わり、CSS の **`font-kerning: normal`** を全体に適用します。  
これにより、「Instagram」「2026年6月」などの英字・数字部分は、  
フォントが持っているカーニング情報を自動で読み取って字間を調整します。

```
例：「Instagram」の文字の並び
  現行（手動）: <span class="en">Instagram</span>  ← 著者が毎回手動でクラス付与が必要
  新システム:   Instagram のまま書くだけ → CSS が自動でカーニング ✅
```

> **カーニング** = 隣り合う文字のペアごとに字間を微調整する機能。  
> 例えば「AV」という組み合わせは、何もしないと間が空きすぎて見えるため、  
> フォントのカーニング情報で詰める調整が入ります。

- Client Component（`'use client'`）として分離し、`useState` で開閉を管理
