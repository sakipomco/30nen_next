### 4-1. DNS向け替え（SAKIがXサーバーの画面で・Claudeが横で案内）

場所: **Xサーバー「サーバーパネル＞ドメイン＞DNSレコード設定」**（send.30nen.com を足したのと同じ画面）

- [ ] `30nen.com`（ホスト名なし＝root）の **Aレコードを `162.43.43.144`（VPS）に**
- [ ] `www.30nen.com` も同じく `162.43.43.144` へ（Aレコード追加）
- ⚠ **触ってはいけないレコード**: `send` 系（Resendメール用のTXT/MX）・既存のMX（`info@30nen.com` などのメール受信用）・`new`（そのまま）
- 反映は早ければ数分〜1時間程度。確認:
  ```bash
  dig +short 30nen.com      # → 162.43.43.144 が返るまで待つ
  dig +short www.30nen.com
  ```

### 4-2. VPS側の受け入れ（SAKIがターミナルで・Claudeがコマンド提示）

- [ ] Nginxの `server_name` に `30nen.com www.30nen.com` を追加（`/etc/nginx/sites-available/30nen`）→ `nginx -t` → `systemctl reload nginx`
- [ ] **httpsの証明書を追加取得**（※DNSがVPSを向いてから実行）:
  ```bash

    --non-interactive --agree-tos -m shigeyasusaki@gmail.com --redirect
  ```
- [ ] `new.30nen.com` は **`https://30nen.com` へ301転送**に変更（練習中のブックマーク・手引きPDFの直リンクを生かすため。証明書はそのまま）

### 4-3. 本番設定ON（.env.local）

- [ ] `/var/www/30nen_next/.env.local` に追記・変更:
  ```
  SITE_URL=https://30nen.com

  ```
  → `pm2 restart 30nen --update-env`
- これで自動的に: **検索エンジンに載る設定ON**（robots/sitemap/meta）＋ **管理画面の「ここは練習用です」バナーが消える**（消し忘れが起きない設計）
