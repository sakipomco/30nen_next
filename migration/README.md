# migration（移行計画フォルダ）

WordPress（現行サイト）から新システムへの**引っ越し（移行）計画**を置く場所です。
記事データの移行スケジュールと、書き手（投稿者）さんの乗り換えスキームをここでまとめます。

> 用語メモ
> - **移行（いこう／migration）** … 古いシステムから新しいシステムへ、データや運用を引っ越すこと。
> - **書き手の乗り換えスキーム** … 20名以上の投稿者さんが、新しい投稿画面へ無理なく移れるようにする段取り（手順・サポート・期間）。

## このフォルダの中身（予定）

| ファイル | 内容 |
|----------|------|
| `README.md` | このフォルダの案内（このファイル） |
| `schedule.md` | 移行スケジュール案（全体の段取りと時期） |
| `writer-onboarding.md` | 書き手さんの乗り換え手順・サポート・アナウンス文面 |
| `data-migration-plan.md` | 記事データ移行の技術手順（Claude Code 用の作業メモ） |
