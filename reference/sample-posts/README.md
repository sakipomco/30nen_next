## ファイル構成
- `posts/<ID>.json` … 記事本体（title / date / author / status / excerpt / content[HTML]）
- `posts/<ID>.categories.json` … その記事のカテゴリ（term_id / name / slug / parent）
- `posts/<ID>.author_id.txt` … 著者ID（WordPressのuser ID。表示名の対応付けは後工程）
- `posts/<ID>.imagelist.txt` … 記事内で使われている画像の相対パス一覧
- `images/` … 上記画像の実ファイル（パス区切りを_に置換して命名）
- `../categories.json` … カテゴリ全体構造（親子関係含む）
