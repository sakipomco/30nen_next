# 30nen.com 移行プロジェクト（新システム）

30nen.com を WordPress から自前システムへ移行するための新規プロジェクト。
現行の WordPress サイトは `../30nen_pj` に温存し、本プロジェクトは別リポジトリとして
クリーンな履歴で構築する（移行方針 B）。

## ゴール

- 管理・運用の手間を減らす
- 約20名の投稿者（ITリテラシー低め）が使いやすいシンプルな投稿画面
- 月額 SaaS 費用ゼロ（サーバー代のみ）
- 既存記事を全件移行

## 技術スタック

| 役割 | 技術 |
|------|------|
| 公開サイト・投稿UI | Next.js (App Router) |
| リッチテキストエディタ | TipTap（OSS・無料） |
| データベース | SQLite（Xサーバー上） |
| 認証 | JWT（メール＋パスワード） |
| ホスティング | Xサーバー（Nginx + PM2） |

## ディレクトリ方針（予定）

```
30nen_next/
├── reference/   ← 現行WPから持ち込む参照物（CSS・画像・カテゴリ構造など）
├── app/         ← Next.js App Router
├── ...
```

## 移行フェーズ

1. サンプルデータのエクスポート（Xサーバーのwp_posts等からJSON＋サンプル画像）
2. 新システム構築（DBスキーマ・CRUD API・JWT認証・デプロイ設定／投稿UI・公開サイトデザイン）
3. 動作確認・調整
4. 全記事の本番移行（一括エクスポート＋インポート＋画像パス書き換え）
5. 本番切り替え（ドメイン切替・WordPress停止）

※ フェーズ1〜3完了・動作確認後にフェーズ4を実施。移行完了までWordPressは並行稼働。
